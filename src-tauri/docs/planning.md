
# Pomodo

A pomodoro to-do list style app


## API

### Goals

- Add sessions with varying length
- Automatic switch between rest and work cycles
  - Can be switched to manual mode
- Track amount of cycles done
- Assign focus times to a specific projects
- Timeblock and plan for day
  - For example set a goal of 4 cycles of School daily
  - Or set a specific goal like 6 cycles tomorrow of Work

- Calendar view of tasks
- Creates a timeline from timeblocked content
- Daily, weekly, monthly summaries of focus cycles
